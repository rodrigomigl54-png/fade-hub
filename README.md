# Fade Hub

Web sajt frizerskog salona Fade Hub (statički HTML/CSS/JS).

## Struktura

```
fade-hub/
├── index.html          # glavna stranica
├── assets/
│   ├── css/            # stilovi (style.css)
│   ├── js/             # skripte (main.js)
│   └── images/         # slike salona, galerija, logo
└── README.md
```

## Pokretanje lokalno

Otvori `index.html` u pregledniku, ili pokreni mali server:

```bash
python3 -m http.server 8000
# zatim otvori http://localhost:8000
```

## Dodavanje slika

Kopiraj slike u `assets/images/` i u HTML-u koristi putanje tipa `assets/images/ime-slike.jpg`.
