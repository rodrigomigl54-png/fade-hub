# Slike

Ovde kopiraj slike iz lokalnog foldera. Sajt već očekuje tačno ove nazive:

| Fajl | Gde se koristi |
| :-- | :-- |
| `assets/logo.jpg` | navigacija, footer, favicon, hero |
| `assets/logo-intro-600.png` | veliki logo u intru (600×600 ili veći) |
| `assets/gallery/rad-1.jpg` … `rad-8.jpg` | galerija (portret 3:4, npr. 1200×1600) |

Dok slike ne postoje, sajt prikazuje tamni placeholder umesto slomljene slike.
Preporuka: JPEG kvalitet ~80, širina do 1200px za galeriju.
