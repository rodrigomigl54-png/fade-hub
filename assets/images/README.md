# Slike

Ovdje kopiraj slike iz lokalnog foldera (npr. `hero.jpg`, `galerija-1.jpg`, `logo.png`).

U HTML-u ih referenciraj relativnom putanjom, npr:

```html
<img src="assets/images/hero.jpg" alt="Fade Hub frizerski salon">
```

Preporuka: `.jpg`/`.webp` za fotografije, `.png`/`.svg` za logo, širina do ~1920px.
